## Portfólio em destaque

### [Spacelink Copa 2026](https://github.com/renylson/spacelink-copa2026)
Plataforma full-stack para gerenciamento de bolão da Copa do Mundo 2026, em produção com usuários reais.

- Autenticação e autorização baseada em perfil (admin/usuário)
- Gerenciamento de partidas, fases, palpites com regras de bloqueio e cálculo automático de pontuação
- Ranking de participantes e painel administrativo
- Ambientes Docker separados para desenvolvimento e produção, com documentação de instalação

### [Super Palpite](https://github.com/renylson/superpalpite)
Aplicação full-stack de portfólio para gerenciamento de bolões de placar exato, com pagamento e testes automatizados.

- Autenticação com múltiplos níveis de permissão (admin / somente leitura)
- Integração com **Mercado Pago** (Pix) e processamento de webhooks de pagamento
- Row Level Security no banco para proteção de dados por usuário
- Testes automatizados com Vitest e CI com GitHub Actions

**Tecnologias:** Next.js · TypeScript · PostgreSQL · Supabase · Mercado Pago · Vitest · GitHub Actions · Docker

## Sobre mim

Minha experiência em tecnologia começou antes da programação. Como Técnico em Telecomunicações na Vivo, trabalho com redes de uma operadora de grande porte, com a responsabilidade que serviços críticos exigem: diagnóstico e resolução de falhas, análise de causa raiz, atuação em ambientes de produção e continuidade de serviço.

Também prestei consultorias a provedores de internet (ISP), atuando em:

- Configuração de roteadores, switches e OLTs
- Instalação e administração de servidores
- Implantação de monitoramento (Zabbix, Grafana, LibreNMS)
- Diagnóstico de lentidão, quedas, perda de pacotes e problemas de rota
- Auditoria de segurança, backup e padronização de configurações
- Documentação de rede e planejamento de expansão/redundância

Hoje transformo essa experiência em software: entendo não só o código de uma aplicação, mas a infraestrutura, a rede e a operação que a mantêm no ar. Busco minha primeira oportunidade profissional dedicada ao desenvolvimento de software, para aprender com profissionais mais experientes e evoluir trabalhando em sistemas reais.
